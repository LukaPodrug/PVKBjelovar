# Store submission pack

Prepared for the first App Store and Google Play submission of the PVK Mladost Bjelovar mobile app.

Files:

- `store-metadata.md` - ready-to-paste store listing metadata.
- `privacy-policy-hr.md` - Croatian privacy policy text matching the public page at `/pravila-privatnosti`.
- `app-store-privacy.md` - App Store Connect privacy nutrition label answers.
- `google-play-data-safety.md` - Google Play Data safety form answers.
- `submission-checklist.md` - final items to complete before review.

Remaining `TODO` values are reviewer account credentials. Create a production test account and paste those credentials into the store forms before submitting.
